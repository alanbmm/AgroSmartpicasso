Conectar una IA generativa (backend seguro)

Para contestar preguntas generales, AgroSmart puede conectarse a un backend de IA. La clave privada se guarda como variable de entorno en el servidor; nunca la escribas aquí ni la publiques en GitHub.

🤖 IA local gratuitaNo iniciada

La IA puede ejecutarse directamente en tu navegador sin API de pago. La primera vez necesita descargar un modelo y un navegador compatible con WebGPU.

El backend externo sigue disponible como opción avanzada, pero no es necesario para la IA local.

Las respuestas locales son orientativas y se basan en los datos disponibles. No sustituyen el criterio técnico agrícola.

      AGROSMART

      Sobre el proyecto

      AgroSmart es un proyecto de agricultura inteligente pensado para observar las condiciones del entorno y ayudar a tomar decisiones sobre el invernadero.

      🌱⚙️
      🎯

      ¿Qué problema resuelve?

      Centraliza meteorología, alertas, historial, sensores y recomendaciones en una sola interfaz para facilitar el seguimiento del invernadero.

      🌡️

      Sensores y datos

      Permite registrar temperatura y humedad interiores y conectar una API de sensores mediante HTTPS. Los datos meteorológicos exteriores proceden de Open-Meteo.

      ⚙️

      Arduino y tecnología

      El proyecto utiliza Arduino y tecnología de sensores para el control y monitorización del invernadero, junto con una aplicación web preparada para funcionar también como PWA.

      Datos y privacidad

      Las preferencias, favoritas, alertas, perfiles y lecturas se guardan localmente en este navegador. Las consultas meteorológicas envían las coordenadas necesarias a Open-Meteo. La geolocalización solo se solicita cuando pulsas el botón correspondiente.
